ANTES DE CRUZAR EL PORTAL

Una última
comprobación.

Algunas respuestas para que la preparación no interrumpa la aventura.

¿Desde dónde se descarga el instalador?

La descarga procede de las versiones publicadas por Gluplandia en GitHub. Puedes revisar la versión enlazada y su huella en el apartado anterior.

¿Qué significa autenticación con Microsoft?

El launcher incluye una modalidad de acceso que utiliza tu cuenta Microsoft para obtener el perfil de Minecraft Java. El inicio de sesión se realiza en la página de Microsoft.

¿El launcher está disponible para macOS o Linux?

La versión publicada que enlazamos es para Windows x64. Puedes usar el launcher oficial de Minecraft para preparar tu cliente en otras plataformas y consultar las instrucciones de la comunidad.

¿Puedo usar este instalador para Bedrock?

Este launcher prepara Minecraft Java. Los detalles de acceso a Gluplandia desde Bedrock se anunciarán por separado.

¿Qué hago si la preparación se interrumpe?

Comprueba tu conexión y el espacio disponible. Revisa el mensaje que muestra la aplicación antes de reintentar. Si el problema continúa, conserva una captura del error para pedir ayuda.

¿Qué hago si Windows muestra una advertencia?

Comprueba que el archivo procede del repositorio enlazado y revisa los datos del aviso. Puedes comparar su huella SHA-256 con la publicada antes de decidir cómo continuar.
